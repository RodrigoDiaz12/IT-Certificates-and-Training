## Adding a Certificate

1. Open the folder that best matches the certificate.
2. Select **Add file → Upload files**.
3. Upload the certificate as a PDF or image.
4. Use a clear filename, such as `comptia-tech-plus.pdf` or `linux-fundamentals-course.pdf`.
5. Commit the upload to the repository.

You do not need to edit this README every time you add a certificate. GitHub will automatically show uploaded files when someone opens the relevant folder.

## File Naming

Use lowercase filenames with hyphens instead of spaces. Include the provider or subject when it helps identify the document.

Examples:

- `comptia-tech-plus.pdf`
- `networking-fundamentals.pdf`
- `linux-fundamentals-course.pdf`
- `intro-to-cybersecurity.pdf`

## Privacy

Before uploading, check each document for personal information you do not want to make public. Consider redacting your home address, date of birth, student or candidate ID, certificate access code, and other sensitive details. Keep verification information private unless you intentionally want it publicly accessible.
